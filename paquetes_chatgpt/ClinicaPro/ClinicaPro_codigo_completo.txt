El plan gratuito tiene disco efímero: la base SQLite (`data/`) **se pierde en cada reinicio o redeploy**. Úselo solo para demostración. Para datos reales:
1. **Disco persistente** (de pago): monte un disco en `/var/data` y fije `CLINICAPRO_DATA_DIR=/var/data`.
2. **PostgreSQL**: requiere adaptar la capa de datos (hoy es SQLite).

Cambiar la clave del administrador tras el primer ingreso (Admin → Mi clave). La variable `CLINICAPRO_ADMIN_PASSWORD` solo se usa mientras no existan usuarios.

==================== ClinicaPro/README.md ====================
# Clínica Pro — Gestión clínica

Sistema web móvil para clínicas y consultas médicas de **cualquier especialidad**: login con roles, agenda con detección de choques (profesional, paciente, sala), ficha de paciente con historial, atenciones con adjuntos (foto/PDF de exámenes), recordatorios de citas para WhatsApp (se copian y se envían a mano), caja con informe diario/mensual, documentos internos de la clínica y exportación a CSV compatible con Excel. No incluye contenido clínico precargado ni servicios de IA: ningún dato sale del servidor.

## Abrir sin complicaciones

### Primera instalación
1. Instalar Python 3.11 o superior desde <https://www.python.org/downloads/>.
2. Descomprimir esta carpeta en el computador de recepción.
3. Ejecutar `install_clinica_pro.ps1` con PowerShell.
4. Ejecutar `run_clinica_pro.bat`. Se abre `http://127.0.0.1:8000`.

Siguientes veces: doble clic en `run_clinica_pro.bat`.
Demostración con datos de ejemplo: `demo_clinica_pro.bat` (no borra datos existentes).
Copia de la base y adjuntos: `backup_clinica_pro.bat`.

## Uso en celulares
Computador y celulares en la misma red Wi-Fi. Buscar la IP con `ipconfig` y abrir `http://IP-DEL-COMPUTADOR:8000`; en el navegador elegir **Agregar a pantalla de inicio**.

## Flujo
1. **Ingreso**: usuario y clave. Roles: *administrador* (usuarios, documentos) y *profesional*. En el primer arranque se crea `admin` con la clave de `CLINICAPRO_ADMIN_PASSWORD` (o una generada en `data/admin_inicial.txt`).
2. **Pacientes**: nombre, RUT (normalizado, no se repite), teléfono, alergias. Al tocar un paciente se abre su **ficha con historial** (citas, atenciones, pagos).
3. **Agenda**: el sistema rechaza choques de profesional, paciente o sala. Estados: En espera, Realizada, Cancelada, No asistió.
4. **Atención**: diagnóstico, tratamiento y adjunto (JPG/PNG/WEBP/PDF, máx. 8 MB); la cita pasa a *Realizada*.
5. **Recordatorios**: lista de citas de mañana (o de otra fecha) con el mensaje listo; botón *Copiar mensaje* y enlace a WhatsApp. **Nada se envía automáticamente.**
6. **Caja**: pagos por medio (efectivo, tarjeta, transferencia, seguro) y **informe de caja diario y mensual**.
7. **Documentos**: módulo opcional donde el administrador sube/edita notas internas (protocolos, consentimientos, tarifas). Viene vacío. No guarde datos de pacientes ahí.
8. Exportar citas y pagos en CSV (separador `;`, UTF-8 con BOM).

## Configuración (variables de entorno)
`CLINICAPRO_NOMBRE`, `CLINICAPRO_ADMIN_USER`, `CLINICAPRO_ADMIN_PASSWORD`, `CLINICAPRO_SECRET` (firma de sesiones), `CLINICAPRO_COOKIE_SECURE=1` (con HTTPS), `CLINICAPRO_DATA_DIR`. Ver `.env.example`. Publicación en Render: `DEPLOY.md`.

## API
Documentación en `/docs` (requiere sesión). Todo `/api` exige sesión salvo `/api/auth/login`, `/api/health` y `/api/meta` (solo el nombre de la clínica). Rutas: `/api/patients` (+`/{id}/history`), `/api/professionals`, `/api/appointments`, `/api/agenda`, `/api/reminders`, `/api/consultations`, `/api/payments`, `/api/reports/cash`, `/api/documents`, `/api/dashboard`, `/api/users`.

## Datos y respaldos
- Base: `data/clinica.db` · Adjuntos: `data/uploads`.
- Para respaldar: `backup_clinica_pro.bat` o copiar la carpeta `data`. No publicar el puerto en Internet.

## Seguridad
Contraseñas con scrypt, sesión en cookie firmada (HttpOnly, SameSite=Strict, Secure con HTTPS), bloqueo tras 5 intentos fallidos, sin secretos en el repositorio y sin llamadas a servicios externos con datos de pacientes. Pendiente para operar con datos reales en Internet: auditoría de accesos, copias automáticas cifradas, base PostgreSQL administrada y cumplimiento de las leyes 19.628 y 20.584. Ver `GUIA_VENTA.md`.

## Validación técnica
```
python -m pytest -q
```
Cubre RUT, choques de agenda, adjuntos, pagos, dashboard, exportación, login y roles, documentos, recordatorios, ficha de paciente e informe de caja.

"""Autenticación: contraseñas con scrypt y sesión en cookie firmada (HMAC-SHA256)."""
import base64
import hashlib
import hmac
import json
import os
import secrets
import time

from .config import DATA_DIR

SESSION_COOKIE = "clinicapro_session"
SESSION_SECONDS = 12 * 3600


def hash_password(password: str, salt: bytes | None = None) -> str:
    salt = salt or secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode(), salt=salt, n=2**14, r=8, p=1, dklen=32)
    return f"scrypt${salt.hex()}${digest.hex()}"


def verify_password(password: str, stored: str) -> bool:
    try:
        _, salt_hex, digest_hex = stored.split("$")
        expected = hash_password(password, bytes.fromhex(salt_hex)).split("$")[2]
    except ValueError:
        return False
    return hmac.compare_digest(expected, digest_hex)


def _secret() -> bytes:
    env = os.getenv("CLINICAPRO_SECRET")
    if env:
        return env.encode()
    path = DATA_DIR / ".secret"
    if not path.exists():
        path.write_text(secrets.token_hex(32))
        try:
            path.chmod(0o600)
        except OSError:
            pass
    return path.read_text().strip().encode()


def _b64(data: bytes) -> str:
    return base64.urlsafe_b64encode(data).decode().rstrip("=")


def make_token(user: dict) -> str:
    payload = _b64(json.dumps({"id": user["id"], "u": user["username"], "r": user["role"], "exp": int(time.time()) + SESSION_SECONDS}).encode())
    return f"{payload}.{_b64(hmac.new(_secret(), payload.encode(), hashlib.sha256).digest())}"


def read_token(token: str | None) -> dict | None:
    if not token or "." not in token:
        return None
    payload, signature = token.rsplit(".", 1)
    expected = _b64(hmac.new(_secret(), payload.encode(), hashlib.sha256).digest())
    if not hmac.compare_digest(signature, expected):
        return None
    try:
        data = json.loads(base64.urlsafe_b64decode(payload + "=" * (-len(payload) % 4)))
    except ValueError:
        return None
    return data if data.get("exp", 0) > time.time() else None


class LoginThrottle:
    """Bloquea 5 minutos tras 5 intentos fallidos por usuario+IP."""

    def __init__(self, limit: int = 5, window: int = 300):
        self.limit, self.window, self.fails = limit, window, {}

    def _recent(self, key):
        now = time.time()
        self.fails[key] = [t for t in self.fails.get(key, []) if now - t < self.window]
        return self.fails[key]

    def blocked(self, key) -> bool:
        return len(self._recent(key)) >= self.limit

    def fail(self, key) -> None:
        self._recent(key).append(time.time())

    def reset(self, key) -> None:
        self.fails.pop(key, None)


throttle = LoginThrottle()

def get_connection() -> sqlite3.Connection:
    connection = sqlite3.connect(str(DATABASE_PATH), check_same_thread=False)
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA foreign_keys = ON")
    return connection


def init_db() -> None:
    connection = get_connection()
    try:
        connection.executescript(SCHEMA)
        connection.execute("DROP TABLE IF EXISTS library_items")  # migración: módulo anterior ya no existe
        connection.commit()
    finally:
        connection.close()


def get_db() -> Generator[sqlite3.Connection, None, None]:
    connection = get_connection()
    try:
        yield connection
    finally:
        connection.close()

import csv
import io
from collections.abc import Iterable
from sqlite3 import Row


def safe_cell(value):
    """Evita inyección de fórmulas en Excel: texto que empieza con = + - @ se antepone con comilla."""
    if value is None:
        return ""
    if isinstance(value, str) and value[:1] in ("=", "+", "-", "@", "\t", "\r"):
        return "'" + value
    return value


class CsvExporter:
    """Exporta filas a CSV con BOM UTF-8 para que Excel respete las tildes."""

    def export(self, rows: Iterable[Row]) -> io.StringIO:
        rows = list(rows)
        stream = io.StringIO()
        stream.write("\ufeff")
        if rows:
            writer = csv.writer(stream, delimiter=";")
            writer.writerow(rows[0].keys())
            for row in rows:
                writer.writerow([safe_cell(value) for value in tuple(row)])
        return stream

def bootstrap_admin(db: sqlite3.Connection) -> None:
    """Crea el administrador inicial si no hay usuarios. La clave sale del entorno o se genera."""
    if db.execute("SELECT COUNT(*) FROM users").fetchone()[0]:
        return
    username = os.getenv("CLINICAPRO_ADMIN_USER", "admin")
    password = os.getenv("CLINICAPRO_ADMIN_PASSWORD")
    if not password:
        password = secrets.token_urlsafe(12)
        (DATA_DIR / "admin_inicial.txt").write_text(f"usuario: {username}\nclave: {password}\n(cámbiela al ingresar y borre este archivo)\n")
    db.execute("INSERT INTO users (username, name, password_hash, role) VALUES (?, ?, ?, 'admin')",
               (username, "Administrador", hash_password(password)))
    db.commit()

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        response = await call_next(request)
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "SAMEORIGIN"
        response.headers["Referrer-Policy"] = "same-origin"
        response.headers["Permissions-Policy"] = "camera=(self), microphone=(), geolocation=()"
        if os.getenv("CLINICAPRO_COOKIE_SECURE") == "1":
            response.headers["Strict-Transport-Security"] = "max-age=31536000"
        if request.url.path.startswith("/api"):
            response.headers["Cache-Control"] = "no-store"  # datos clínicos: nunca en caché del navegador/proxy
        if response.headers.get("content-type", "").startswith("text/html") and not request.url.path.startswith(("/docs", "/redoc")):
            response.headers["Content-Security-Policy"] = (
                "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; "
                "img-src 'self' data: blob:; connect-src 'self'; object-src 'none'; base-uri 'none'; "
                "form-action 'self'; frame-ancestors 'self'")
        return response


PUBLIC_PATHS = {"/api/auth/login", "/api/health", "/api/meta"}


class AuthMiddleware(BaseHTTPMiddleware):
    """Todo lo que cuelga de /api y la documentación exige sesión válida."""

    async def dispatch(self, request: Request, call_next):
        path = request.url.path
        protected = path.startswith(("/api", "/docs", "/redoc", "/openapi"))
        request.state.user = read_token(request.cookies.get(SESSION_COOKIE))
        if protected and path not in PUBLIC_PATHS and request.state.user is None:
            return JSONResponse({"detail": "Sesión requerida"}, status_code=401)
        return await call_next(request)

class LoginIn(BaseModel):
    username: str = Field(min_length=1, max_length=60)
    password: str = Field(min_length=1, max_length=200)


@app.post("/api/auth/login")
def login(payload: LoginIn, request: Request, db: sqlite3.Connection = Depends(get_db)) -> Response:
    key = (payload.username.lower(), request.client.host if request.client else "-")
    if throttle.blocked(key):
        raise HTTPException(429, "Demasiados intentos; espere 5 minutos")
    row = db.execute("SELECT * FROM users WHERE username = ? AND active = 1", (payload.username,)).fetchone()
    if row is None or not verify_password(payload.password, row["password_hash"]):
        throttle.fail(key)
        raise HTTPException(401, "Usuario o clave incorrectos")
    throttle.reset(key)
    user = {"id": row["id"], "username": row["username"], "role": row["role"], "name": row["name"]}
    response = JSONResponse(user)
    response.set_cookie(SESSION_COOKIE, make_token(user), max_age=SESSION_SECONDS, httponly=True, samesite="strict",
                        secure=os.getenv("CLINICAPRO_COOKIE_SECURE") == "1")
    return response


@app.post("/api/auth/logout")
def logout() -> Response:
    response = JSONResponse({"ok": True})
    response.delete_cookie(SESSION_COOKIE)
    return response

class PasswordIn(BaseModel):

    new: str = Field(min_length=10, max_length=200)


@app.post("/api/auth/password")
def change_password(payload: PasswordIn, request: Request, db: sqlite3.Connection = Depends(get_db)) -> dict[str, bool]:
    row = db.execute("SELECT * FROM users WHERE id = ?", (request.state.user["id"],)).fetchone()
    if row is None or not verify_password(payload.current, row["password_hash"]):
        raise HTTPException(403, "La clave actual no coincide")
    db.execute("UPDATE users SET password_hash = ? WHERE id = ?", (hash_password(payload.new), row["id"]))
    db.commit()
    return {"ok": True}

@app.post("/api/users", status_code=201)
def create_user(payload: UserIn, request: Request, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
    admin_only(request)
    if payload.role not in ("admin", "profesional") or not payload.password:
        raise HTTPException(422, "Rol no válido o clave faltante (mínimo 10 caracteres)")
    try:
        cursor = db.execute("INSERT INTO users (username, name, password_hash, role, active) VALUES (?,?,?,?,?)",
                            (payload.username, payload.name, hash_password(payload.password), payload.role, int(payload.active)))
        db.commit()
    except sqlite3.IntegrityError as error:

def fold(text: str | None) -> str:
    return "".join(c for c in unicodedata.normalize("NFD", (text or "").lower()) if unicodedata.category(c) != "Mn")

def row_dict(row: sqlite3.Row) -> dict[str, Any]:

def normalize_rut(rut: str | None) -> str | None:
    if rut is None:
        return None
    cleaned = "".join(ch for ch in rut.upper() if ch.isalnum())
    if not cleaned:
        return None
    return f"{cleaned[:-1]}-{cleaned[-1]}" if len(cleaned) > 1 else cleaned


def parse_start(value: str) -> datetime:
    try:
        return datetime.fromisoformat(value)
    except ValueError as error:
        raise HTTPException(422, "Fecha/hora inválida (use AAAA-MM-DDTHH:MM)") from error


def bind(values: dict[str, Any], columns: tuple[str, ...]) -> tuple:
    return tuple(int(values[c]) if isinstance(values[c], bool) else values[c] for c in columns)


def crud_router(table: str, model: type[BaseModel], columns: tuple[str, ...], before_save=None):
    """CRUD pequeño y consistente para una tabla. `before_save` puede validar/normalizar."""
    prefix = f"/api/{table}"

    def prepare(payload: BaseModel, db: sqlite3.Connection, item_id: int | None = None) -> dict:
        values = payload.model_dump()
        if before_save:
            before_save(values, db, item_id)
        return values

    @app.get(prefix)
    def list_items(db: sqlite3.Connection = Depends(get_db)) -> list[dict[str, Any]]:
        return [row_dict(r) for r in db.execute(f"SELECT * FROM {table} ORDER BY id DESC")]

    @app.get(f"{prefix}/{{item_id}}")
    def get_item(item_id: int, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
        row = db.execute(f"SELECT * FROM {table} WHERE id = ?", (item_id,)).fetchone()
        if row is None:
            raise HTTPException(404, "Registro no encontrado")
        return row_dict(row)

    @app.post(prefix, status_code=201)
    def create_item(payload: model, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:  # type: ignore[valid-type]
        values = prepare(payload, db)
        try:
            cursor = db.execute(
                f"INSERT INTO {table} ({', '.join(columns)}) VALUES ({', '.join('?' for _ in columns)})",
                bind(values, columns),
            )
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, f"Registro duplicado o referencia inválida: {error}") from error
        return row_dict(db.execute(f"SELECT * FROM {table} WHERE id = ?", (cursor.lastrowid,)).fetchone())

    @app.put(f"{prefix}/{{item_id}}")
    def update_item(item_id: int, payload: model, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:  # type: ignore[valid-type]
        values = prepare(payload, db, item_id)
        assignments = ", ".join(f"{c} = ?" for c in columns)
        try:
            cursor = db.execute(
                f"UPDATE {table} SET {assignments} WHERE id = ?", bind(values, columns) + (item_id,)
            )
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, f"Registro duplicado o referencia inválida: {error}") from error
        if cursor.rowcount == 0:
            raise HTTPException(404, "Registro no encontrado")
        return row_dict(db.execute(f"SELECT * FROM {table} WHERE id = ?", (item_id,)).fetchone())

    @app.delete(f"{prefix}/{{item_id}}", status_code=204)
    def delete_item(item_id: int, request: Request, db: sqlite3.Connection = Depends(get_db)) -> None:
        admin_only(request)
        try:
            cursor = db.execute(f"DELETE FROM {table} WHERE id = ?", (item_id,))
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, "Tiene registros asociados; desactívelo en vez de borrarlo") from error
        if cursor.rowcount == 0:
            raise HTTPException(404, "Registro no encontrado")


def patient_rules(values: dict, db: sqlite3.Connection, item_id: int | None) -> None:
    values["rut"] = normalize_rut(values["rut"])


def payment_rules(values: dict, db: sqlite3.Connection, item_id: int | None) -> None:
    if values["method"] not in METHODS:
        raise HTTPException(422, "Medio de pago no válido")


def appointment_rules(values: dict, db: sqlite3.Connection, item_id: int | None) -> None:
    if values["status"] not in STATUSES:
        raise HTTPException(422, "Estado no válido")
    start = parse_start(values["starts_at"])
    values["starts_at"] = start.strftime("%Y-%m-%dT%H:%M")
    if values["status"] in ("cancelled", "no_show"):
        return
    end = start + timedelta(minutes=values["duration_min"])
    rows = db.execute(
        """SELECT id, starts_at, duration_min, room, professional_id, patient_id FROM appointments
           WHERE status IN ('scheduled','arrived') AND date(starts_at) = date(?) AND id IS NOT ?""",
        (values["starts_at"], item_id),
    )
    for row in rows:
        other_start = datetime.fromisoformat(row["starts_at"])
        other_end = other_start + timedelta(minutes=row["duration_min"])
        if not (start < other_end and other_start < end):
            continue
        if row["professional_id"] == values["professional_id"]:
            raise HTTPException(409, "El profesional ya tiene una cita en ese horario")
        if row["patient_id"] == values["patient_id"]:
            raise HTTPException(409, "El paciente ya tiene una cita en ese horario")
        if values["room"] and row["room"] == values["room"]:
            raise HTTPException(409, "La sala ya está ocupada en ese horario")

MAGIC = {".jpg": (b"\xff\xd8\xff",), ".jpeg": (b"\xff\xd8\xff",), ".png": (b"\x89PNG\r\n\x1a\n",), ".pdf": (b"%PDF-",)}


def _looks_like(extension: str, content: bytes) -> bool:
    """Verifica la firma real del archivo, no solo la extensión."""
    if extension == ".webp":
        return content[:4] == b"RIFF" and content[8:12] == b"WEBP"
    return any(content.startswith(sig) for sig in MAGIC.get(extension, ()))

@app.post("/api/consultations", status_code=201)
async def create_consultation(
    patient_id: int = Form(...),
    professional_id: int = Form(...),
    appointment_id: int | None = Form(None),
    diagnosis: str | None = Form(None),
    treatment: str | None = Form(None),
    notes: str | None = Form(None),
    attachment: UploadFile | None = File(None),
    db: sqlite3.Connection = Depends(get_db),
) -> dict[str, Any]:
    stored: str | None = None
    if attachment and attachment.filename:
        extension = Path(attachment.filename).suffix.lower()
        if extension not in {".jpg", ".jpeg", ".png", ".webp", ".pdf"}:
            raise HTTPException(415, "Solo se aceptan JPG, PNG, WEBP o PDF")
        content = await attachment.read(MAX_UPLOAD_BYTES + 1)
        if len(content) > MAX_UPLOAD_BYTES:
            raise HTTPException(413, "El archivo excede el tamaño máximo permitido")
        if not _looks_like(extension, content):
            raise HTTPException(415, "El contenido del archivo no coincide con su tipo")
        stored = f"{datetime.now(timezone.utc):%Y%m%d%H%M%S}_{secrets.token_hex(8)}{extension}"
        (UPLOAD_DIR / stored).write_bytes(content)
    try:
        cursor = db.execute(
            """INSERT INTO consultations (patient_id, professional_id, appointment_id, diagnosis, treatment, notes, attachment_path)
               VALUES (?, ?, ?, ?, ?, ?, ?)""",
            (patient_id, professional_id, appointment_id, diagnosis, treatment, notes, stored),
        )
        if appointment_id is not None:
            db.execute("UPDATE appointments SET status = 'done' WHERE id = ?", (appointment_id,))
        db.commit()
    except sqlite3.IntegrityError as error:
        if stored:
            (UPLOAD_DIR / stored).unlink(missing_ok=True)
        raise HTTPException(409, f"Referencia inválida: {error}") from error
    return row_dict(db.execute(CONSULTATION_SELECT + " WHERE c.id = ?", (cursor.lastrowid,)).fetchone())

            digits = "56" + digits
        item["whatsapp_url"] = f"https://wa.me/{digits}" if digits else None
        out.append(item)
    return out

@app.get("/api/reports/cash")
def cash_report(period: str = Query(default="day", pattern="^(day|month)$"),
                date: str | None = Query(default=None, description="AAAA-MM-DD (día) o AAAA-MM (mes); por defecto hoy/este mes"),
                db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
    now = datetime.now()
    if period == "day":
        date = date or now.strftime("%Y-%m-%d")
        fmt, value = "%Y-%m-%d", date
    else:
        date = (date or now.strftime("%Y-%m"))[:7]
        fmt, value = "%Y-%m", date
    try:
        datetime.strptime(value, fmt)
    except ValueError as error:
        raise HTTPException(422, "Fecha inválida") from error
    rows = db.execute(f"SELECT method, COUNT(*) AS n, SUM(amount) AS total FROM payments WHERE strftime('{fmt}', paid_at) = ? GROUP BY method", (value,))
    by_method = {r["method"]: {"count": r["n"], "total": r["total"]} for r in rows}
    items = db.execute(
        f"""SELECT y.id, y.paid_at, y.concept, y.amount, y.method, p.name AS patient_name FROM payments y
            JOIN patients p ON p.id = y.patient_id WHERE strftime('{fmt}', y.paid_at) = ? ORDER BY y.paid_at""", (value,))
    return {"period": period, "date": value, "total": sum(m["total"] for m in by_method.values()),
            "count": sum(m["count"] for m in by_method.values()), "by_method": by_method, "payments": [dict(r) for r in items]}

from datetime import datetime, timedelta


def _when(days, hour=10):
    return (datetime.now() + timedelta(days=days)).replace(hour=hour, minute=0).strftime("%Y-%m-%dT%H:%M")

    patient, other, doctor = base
    client.put(f"/api/patients/{patient['id']}", json={"name": "Ana Soto", "rut": "12.345.678-5", "phone": "9 5555 0001"})
    manana = client.post("/api/appointments", json={"patient_id": patient["id"], "professional_id": doctor["id"], "starts_at": _when(1)}).json()
    client.post("/api/appointments", json={"patient_id": other["id"], "professional_id": doctor["id"], "starts_at": _when(1, 12), "status": "cancelled"})
    client.post("/api/appointments", json={"patient_id": other["id"], "professional_id": doctor["id"], "starts_at": _when(3)})
    r = client.get("/api/reminders").json()
    assert [x["id"] for x in r] == [manana["id"]]  # ni canceladas ni otros días
    assert "Ana" in r[0]["message"] and "Dra. Rojas" in r[0]["message"] and "10:00" in r[0]["message"]
    assert r[0]["whatsapp_url"] == "https://wa.me/56955550001"
    assert client.get("/api/reminders", params={"day": _when(3)[:10]}).json()[0]["patient_name"] == "Luis Pérez"
