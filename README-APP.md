## 🚀 Inicio Rápido

### Opción 1: Aplicación de Escritorio (Recomendado)

```bash
cd ~/njjj
python3 app.py
```

Interfaz gráfica simple:
- 🎬 Un botón principal: **GENERAR VIDEO AHORA**
- 📊 Monitor de progreso en tiempo real
- 📁 Acceso a videos generados

### Opción 2: Línea de Comandos

```bash
cd ~/njjj
python3 scripts/random-video-generator.py
```

### Opción 3: Sistema Automático

```bash
cd ~/njjj
node video-automation-engine.js submit '{"prompt":"tu concepto"}'
node video-automation-engine.js process
```

## 📊 Características

✅ **Una Sola Opción**
- Click en "Generar Video"
- Sistema automático hace el resto
- Sin configuración complicada

✅ **Videos Profesionales**
- Resolución: 1080×1920 (vertical)
- Codec: H.264
- Calidad: CRF 14 (profesional)
- Audio: AAC 192kbps

✅ **5 Plataformas**
- YouTube Shorts
- TikTok
- Instagram Reels
- Facebook
- Twitter

✅ **Completamente Automático**
- Generación: 4-5 minutos
- Capacidad: 288-432 videos/día
- Cero intervención manual

## 🎯 Uso

### En la aplicación gráfica:

1. Ejecutar: `python3 app.py`
2. Click: "🚀 GENERAR VIDEO AHORA"
3. Esperar: 4-5 minutos
4. Ver: Videos en ~/njjj/exports/
5. Publicar: Usa publish_to_youtube.sh
