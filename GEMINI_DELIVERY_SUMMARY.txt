FUNCIONALIDADES IMPLEMENTADAS:
───────────────────────────────────────────────────────────────────────────────

✅ GEMINI VISION API (Análisis de Imágenes)
   • Analiza fotos de Instagram automáticamente
   • Extrae: Composición, colores, calidad, mood
   • Genera: Descripción SEO, hashtags, mejoras
   • Soporta: JPEG, PNG, GIF, WEBP
   • Tamaño máximo: 20MB

✅ GEMINI PRO (Generación de Contenido)
   • Genera captions optimizados para Instagram
   • Crea micro-copy y CTAs efectivos
   • Redacta testimonios realistas
   • Propone hashtags trending
   • Personalizable con custom prompts

✅ VIDEO PROMPTS (Runway/Pika)
   • Genera 3 prompts profesionales
   • Optimizados para Runway ML
   • Optimizados para Pika AI
   • Formato: Ready to copy-paste
   • Incluye: Escena, lighting, audio, text overlay, CTA

✅ PREDICCIÓN DE ENGAGEMENT
   • Estima: Views, likes, comments, shares
   • Recomienda: Mejor hora/día de publicación
   • Sugiere: Tipo de contenido más engagable
   • Identifica: Tendencias a explotar
   • Propone: Variaciones de contenido

✅ BATCH PROCESSING
   • Analiza múltiples imágenes de una vez
   • Exporta resultados en CSV
   • Rate limiting (1s entre imágenes)
   • Ideal para: Análisis de archivo completo

✅ SEGURIDAD
   • Backend proxy (no expone API Key en frontend)
   • CORS configurado
   • Validación de entradas
   • Manejo de errores
   • Logging de llamadas
   • Cache de resultados

CÓMO EMPEZAR (RESUMEN):
───────────────────────────────────────────────────────────────────────────────

1. OBTENER API KEY (5 minutos)
   → Ve a console.cloud.google.com
   → Crea proyecto "Artesanos AI"
   → Activa "Google Generative AI API"
   → Crea API Key
   → Copia la clave

2. CONFIGURAR PROYECTO (2 minutos)
   → cp .env.example .env.local
   → Abre .env.local
   → Pega tu API Key en GEMINI_API_KEY
   → Guarda

3. INSTALAR DEPENDENCIAS (1 minuto)
   → cd server
   → npm install @google/generative-ai dotenv node-fetch

4. INICIAR SERVIDOR (1 minuto)
   → npm start
   → Verifica: "✅ Gemini AI initialized successfully"

5. ABRIR LANDING PAGE (1 minuto)
   → http://localhost:3000/artesanos.html
   → ¡Listo!

TIEMPO TOTAL: ~10 minutos
