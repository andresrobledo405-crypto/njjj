# KinePro — Gestión y biblioteca para kinesiólogos

App web móvil (español, Chile) para consultas de kinesiología: pacientes, agenda por **plan de tratamiento** (ej. “10 sesiones”), atenciones con **EVA y rangos medidos por sesión** con gráfico de evolución, **hojas de ejercicios para el hogar** imprimibles/PDF armadas desde la biblioteca, caja, login con roles (admin/profesional) y una **biblioteca de kinesiología de 115 entradas** con asistente opcional “Preguntar con IA”.

> ⚠ **Aviso:** el contenido clínico de la biblioteca fue redactado con apoyo de IA y **no está validado por un kinesiólogo**. El aviso es visible en la app y en las hojas para el profesional. `revision_gpt/` contiene el paquete para revisarlo; las correcciones se incorporan editando `app/library_data.txt` (no se inventan citas ni cifras).

## Novedades kinesiológicas
- **Planes**: pestaña Pacientes → ficha → *Nuevo plan* (motivo de consulta, diagnóstico kinésico, N sesiones). Progreso “4 de 10”; *Agendar sesiones* crea la serie (cada N días) omitiendo choques; el plan se cierra solo al completar las sesiones.
- **Atención**: desde la agenda (*Registrar atención*) o la pestaña Atención: plan, EVA 0–10 (toque), mediciones (movimiento, valor, ° o cm), enlaces a entradas de la biblioteca, adjunto.
- **Evolución**: ficha → plan → *Evolución*: gráficos de EVA y de cada medición por sesión.
- **Ejercicios para el hogar**: Biblioteca → *Ejercicios para el hogar*: plantillas con ejercicios de la biblioteca y dosis que define el profesional; *Imprimir / PDF* (con nombre del paciente) abre una hoja lista para imprimir o “Guardar como PDF”.

## Abrir sin complicaciones

### Primera instalación
1. Instalar Python 3.11 o superior desde <https://www.python.org/downloads/>.
2. Descomprimir esta carpeta en el computador de recepción.
3. Ejecutar `install_kinepro.ps1` con PowerShell.
4. Ejecutar `run_kinepro.bat`. Se abre `http://127.0.0.1:8000`.

Siguientes veces: doble clic en `run_kinepro.bat`.
Demostración con datos de ejemplo: `demo_kinepro.bat` (no borra datos existentes).
Copia de la base y adjuntos: `backup_kinepro.bat`.

## Uso en celulares
Computador y celulares en la misma red Wi-Fi. Buscar la IP con `ipconfig` y abrir `http://IP-DEL-COMPUTADOR:8000`; en el navegador elegir **Agregar a pantalla de inicio**.

## Flujo
1. **Pacientes**: registrar nombre, RUT (se normaliza y no se repite), teléfono, alergias.
2. **Agenda**: agendar cita; el sistema rechaza choques de horario del profesional, del paciente o de la sala. Cambiar estado: En espera, Realizada, Cancelada, No asistió (una cita cancelada libera el horario).
3. **Atención**: registrar diagnóstico, tratamiento y adjuntar examen (JPG/PNG/WEBP/PDF, máx. 8 MB). La cita asociada pasa a *Realizada*.
4. **Caja**: registrar pagos (efectivo, tarjeta, transferencia, seguro). El panel muestra ingresos del mes.
5. Descargar citas y pagos en CSV (separador `;`, UTF-8 con BOM, abre directo en Excel).

def get_connection() -> sqlite3.Connection:
    connection = sqlite3.connect(str(DATABASE_PATH), check_same_thread=False)
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA foreign_keys = ON")
    return connection


MIGRATIONS = (
    ("patients", "occupation", "TEXT"),
    ("patients", "history", "TEXT"),
    ("appointments", "plan_id", "INTEGER REFERENCES treatment_plans(id)"),
    ("consultations", "plan_id", "INTEGER REFERENCES treatment_plans(id)"),
    ("consultations", "eva", "INTEGER CHECK (eva IS NULL OR (eva >= 0 AND eva <= 10))"),
)


def _migrate(connection: sqlite3.Connection) -> None:
    """Agrega columnas nuevas a bases creadas por versiones anteriores."""
    for table, column, definition in MIGRATIONS:
        if column not in {row["name"] for row in connection.execute(f"PRAGMA table_info({table})")}:
            connection.execute(f"ALTER TABLE {table} ADD COLUMN {column} {definition}")


def init_db() -> None:
    connection = get_connection()
    try:
        connection.executescript(SCHEMA)
        _migrate(connection)
        connection.commit()
    finally:
        connection.close()


def get_db() -> Generator[sqlite3.Connection, None, None]:
    connection = get_connection()
    try:
        yield connection
    finally:
        connection.close()

"""Autenticación: contraseñas con scrypt y sesión en cookie firmada (HMAC-SHA256)."""
import base64
import hashlib
import hmac
import json
import os
import secrets
import time

from .config import DATA_DIR

SESSION_COOKIE = "kinepro_session"
SESSION_SECONDS = 12 * 3600


def hash_password(password: str, salt: bytes | None = None) -> str:
    salt = salt or secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode(), salt=salt, n=2**14, r=8, p=1, dklen=32)
    return f"scrypt${salt.hex()}${digest.hex()}"


def verify_password(password: str, stored: str) -> bool:
    try:
        _, salt_hex, digest_hex = stored.split("$")
        expected = hash_password(password, bytes.fromhex(salt_hex)).split("$")[2]
    except ValueError:
        return False
    return hmac.compare_digest(expected, digest_hex)


def _secret() -> bytes:
    env = os.getenv("KINEPRO_SECRET")
    if env:
        return env.encode()
    path = DATA_DIR / ".secret"
    if not path.exists():
        path.write_text(secrets.token_hex(32))
        try:
            path.chmod(0o600)
        except OSError:
            pass
    return path.read_text().strip().encode()


def _b64(data: bytes) -> str:
    return base64.urlsafe_b64encode(data).decode().rstrip("=")


def make_token(user: dict) -> str:
    payload = _b64(json.dumps({"id": user["id"], "u": user["username"], "r": user["role"], "exp": int(time.time()) + SESSION_SECONDS}).encode())
    return f"{payload}.{_b64(hmac.new(_secret(), payload.encode(), hashlib.sha256).digest())}"


def read_token(token: str | None) -> dict | None:
    if not token or "." not in token:
        return None
    payload, signature = token.rsplit(".", 1)
    expected = _b64(hmac.new(_secret(), payload.encode(), hashlib.sha256).digest())
    if not hmac.compare_digest(signature, expected):
        return None
    try:
        data = json.loads(base64.urlsafe_b64decode(payload + "=" * (-len(payload) % 4)))
    except ValueError:
        return None
    return data if data.get("exp", 0) > time.time() else None


class LoginThrottle:
    """Bloquea 5 minutos tras 5 intentos fallidos por usuario+IP."""

    def __init__(self, limit: int = 5, window: int = 300):
        self.limit, self.window, self.fails = limit, window, {}

    def _recent(self, key):
        now = time.time()
        self.fails[key] = [t for t in self.fails.get(key, []) if now - t < self.window]
        return self.fails[key]

    def blocked(self, key) -> bool:
        return len(self._recent(key)) >= self.limit

    def fail(self, key) -> None:
        self._recent(key).append(time.time())

    def reset(self, key) -> None:
        self.fails.pop(key, None)


throttle = LoginThrottle()

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        response = await call_next(request)
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "SAMEORIGIN"
        response.headers["Referrer-Policy"] = "same-origin"
        if request.url.scheme == "https":
            response.headers["Strict-Transport-Security"] = "max-age=15552000; includeSubDomains"
        response.headers["Content-Security-Policy"] = ("default-src 'self'; script-src 'self'; "
                                                       "style-src 'self' 'unsafe-inline'; img-src 'self' data:; frame-ancestors 'self'; object-src 'none'; base-uri 'none'; form-action 'self'")

PUBLIC_PATHS = {"/api/auth/login", "/api/health", "/api/meta"}


class AuthMiddleware(BaseHTTPMiddleware):
    """Todo lo que cuelga de /api y la documentación exige sesión válida."""

    async def dispatch(self, request: Request, call_next):
        path = request.url.path
        protected = path.startswith(("/api", "/docs", "/redoc", "/openapi"))
        user = read_token(request.cookies.get(SESSION_COOKIE))
        if user is not None:  # revalida contra la base: usuario desactivado o con otro rol pierde la sesión
            db = get_connection()
            try:
                row = db.execute("SELECT role FROM users WHERE id = ? AND active = 1", (user["id"],)).fetchone()
            finally:
                db.close()
            user = {**user, "r": row["role"]} if row else None
        request.state.user = user
        if protected and path not in PUBLIC_PATHS and request.state.user is None:
            return JSONResponse({"detail": "Sesión requerida"}, status_code=401)
        response = await call_next(request)
        if user is not None and path.startswith("/api") and path != "/api/admin/audit" and (
                request.method != "GET" or SENSITIVE_GET.match(path)):
            audit(user, request.method, path, response.status_code)
        return response

@app.post("/api/auth/login")
def login(payload: LoginIn, request: Request, db: sqlite3.Connection = Depends(get_db)) -> Response:
    key = (payload.username.lower(), request.client.host if request.client else "-")
    if throttle.blocked(key):
        raise HTTPException(429, "Demasiados intentos; espere 5 minutos")
    row = db.execute("SELECT * FROM users WHERE username = ? AND active = 1", (payload.username,)).fetchone()
    if row is None or not verify_password(payload.password, row["password_hash"]):
        throttle.fail(key)
        audit(None, "POST", "/api/auth/login", 401, payload.username[:60])
        raise HTTPException(401, "Usuario o clave incorrectos")
    throttle.reset(key)
    audit({"id": row["id"], "u": row["username"]}, "POST", "/api/auth/login", 200)
    user = {"id": row["id"], "username": row["username"], "role": row["role"], "name": row["name"]}
    response = JSONResponse(user)
    response.set_cookie(SESSION_COOKIE, make_token(user), max_age=SESSION_SECONDS, httponly=True, samesite="strict",
                        secure=os.getenv("KINEPRO_COOKIE_SECURE") == "1" or request.url.scheme == "https")
    return response

def fold(text: str | None) -> str:
    return "".join(c for c in unicodedata.normalize("NFD", (text or "").lower()) if unicodedata.category(c) != "Mn")

@app.get("/api/library")
def library_search(q: str | None = None, category: str | None = None, region: str | None = None,
                   db: sqlite3.Connection = Depends(get_db)) -> list[dict[str, Any]]:
    sql, params = "SELECT * FROM library_items WHERE 1=1", []
    if category:
        sql, params = sql + " AND category = ?", [*params, category]
    if region:
        sql, params = sql + " AND region = ?", [*params, region]
    rows = [dict(r) for r in db.execute(sql + " ORDER BY category, title", params)]
    if q:
        terms = fold(q).split()
        def haystack(r): return fold(" ".join(str(r[c] or "") for c in ("title", "summary", "content", "tags", "region", "precautions")))
        def rank(r):
            title = fold(r["title"])
            return -sum(3 if t in title else 1 for t in terms)
        rows = sorted((r for r in rows if all(t in haystack(r) for t in terms)), key=rank)
    return rows

ASK_PROMPT = (
    "Eres un asistente de apoyo educativo para kinesiólogos. Responde en español, de forma breve y clara, "
    "usando EXCLUSIVAMENTE las entradas de la biblioteca entregadas como contexto. Si el contexto no alcanza "
    "para responder, dilo y sugiere consultar guías clínicas o a un especialista. No des diagnósticos ni "
    "indicaciones para un paciente concreto. Menciona siempre las precauciones y banderas rojas pertinentes. "
    "Cita las entradas usadas por su título entre corchetes."
)
ask_log: dict[int, list[float]] = {}
ASK_LIMIT_PER_HOUR = int(os.getenv("KINEPRO_ASK_LIMIT", "20"))


@app.post("/api/library/ask")
def library_ask(payload: AskIn, request: Request, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
    """Pregunta a un modelo de OpenAI. Solo se envían la pregunta y entradas de la biblioteca; nunca datos de pacientes."""
    api_key = os.getenv("OPENAI_API_KEY")
    if not api_key:
        raise HTTPException(503, "El asistente no está activado (falta OPENAI_API_KEY)")
    uid, now = request.state.user["id"], time.time()
    recent = [t for t in ask_log.get(uid, []) if now - t < 3600]
    if len(recent) >= ASK_LIMIT_PER_HOUR:
        raise HTTPException(429, "Límite de preguntas por hora alcanzado")
    ask_log[uid] = recent + [now]
    # recuperación: entradas que coinciden con más palabras de la pregunta
    words = [w for w in fold(payload.question).replace("?", " ").replace(",", " ").split() if len(w) > 3]
    scored = []
    for row in db.execute("SELECT * FROM library_items"):
        text = fold(" ".join(str(row[c] or "") for c in ("title", "summary", "content", "tags", "region")))
        title = fold(row["title"])
        score = sum((3 if w in title else 1) for w in words if w in text)
        if score:
            scored.append((score, dict(row)))
    top = [r for _, r in sorted(scored, key=lambda x: -x[0])[:6]]
    if not top:
        return {"answer": "No encontré información sobre eso en la biblioteca. Intente con otras palabras o consulte guías clínicas.", "sources": []}
    context = "\n\n".join(f"[{r['title']}]\n{r['summary'] or ''}\n{r['content'] or ''}\nPrecauciones: {r['precautions'] or '-'}" for r in top)
    try:
        response = httpx.post(
            "https://api.openai.com/v1/chat/completions",
            headers={"Authorization": f"Bearer {api_key}"},
            json={"model": os.getenv("OPENAI_MODEL", "gpt-4o-mini"), "temperature": 0.2,
                  "messages": [{"role": "system", "content": ASK_PROMPT},
                               {"role": "user", "content": f"Contexto:\n{context}\n\nPregunta: {payload.question}"}]},
            timeout=40,
        )
        response.raise_for_status()
        answer = response.json()["choices"][0]["message"]["content"]
    except (httpx.HTTPError, KeyError, IndexError, ValueError) as error:
        raise HTTPException(502, "El servicio de IA no respondió; intente más tarde") from error
    return {"answer": answer, "sources": [{"id": r["id"], "title": r["title"]} for r in top]}

MAGIC = {".pdf": (b"%PDF",), ".png": (b"\x89PNG\r\n\x1a\n",), ".jpg": (b"\xff\xd8\xff",), ".jpeg": (b"\xff\xd8\xff",)}


def looks_like(extension: str, content: bytes) -> bool:
    """Comprueba los primeros bytes (firma) para no aceptar otro tipo de archivo con extensión cambiada."""
    if extension == ".webp":
        return content[:4] == b"RIFF" and content[8:12] == b"WEBP"
    return content.startswith(MAGIC.get(extension, (b"",)))


def row_dict(row: sqlite3.Row) -> dict[str, Any]:

def normalize_rut(rut: str | None) -> str | None:
    if rut is None:
        return None
    cleaned = "".join(ch for ch in rut.upper() if ch.isalnum())
    if not cleaned:
        return None
    return f"{cleaned[:-1]}-{cleaned[-1]}" if len(cleaned) > 1 else cleaned


def parse_start(value: str) -> datetime:
    try:
        return datetime.fromisoformat(value)
    except ValueError as error:
        raise HTTPException(422, "Fecha/hora inválida (use AAAA-MM-DDTHH:MM)") from error


def bind(values: dict[str, Any], columns: tuple[str, ...]) -> tuple:
    return tuple(int(values[c]) if isinstance(values[c], bool) else values[c] for c in columns)


def crud_router(table: str, model: type[BaseModel], columns: tuple[str, ...], before_save=None):
    """CRUD pequeño y consistente para una tabla. `before_save` puede validar/normalizar."""
    prefix = f"/api/{table}"

    def prepare(payload: BaseModel, db: sqlite3.Connection, item_id: int | None = None) -> dict:
        values = payload.model_dump()
        if before_save:
            before_save(values, db, item_id)
        return values

    @app.get(prefix)
    def list_items(db: sqlite3.Connection = Depends(get_db)) -> list[dict[str, Any]]:
        return [row_dict(r) for r in db.execute(f"SELECT * FROM {table} ORDER BY id DESC")]

    @app.get(f"{prefix}/{{item_id}}")
    def get_item(item_id: int, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
        row = db.execute(f"SELECT * FROM {table} WHERE id = ?", (item_id,)).fetchone()
        if row is None:
            raise HTTPException(404, "Registro no encontrado")
        return row_dict(row)

    @app.post(prefix, status_code=201)
    def create_item(payload: model, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:  # type: ignore[valid-type]
        values = prepare(payload, db)
        try:
            cursor = db.execute(
                f"INSERT INTO {table} ({', '.join(columns)}) VALUES ({', '.join('?' for _ in columns)})",
                bind(values, columns),
            )
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, f"Registro duplicado o referencia inválida: {error}") from error
        return row_dict(db.execute(f"SELECT * FROM {table} WHERE id = ?", (cursor.lastrowid,)).fetchone())

    @app.put(f"{prefix}/{{item_id}}")
    def update_item(item_id: int, payload: model, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:  # type: ignore[valid-type]
        values = prepare(payload, db, item_id)
        assignments = ", ".join(f"{c} = ?" for c in columns)
        try:
            cursor = db.execute(
                f"UPDATE {table} SET {assignments} WHERE id = ?", bind(values, columns) + (item_id,)
            )
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, f"Registro duplicado o referencia inválida: {error}") from error
        if cursor.rowcount == 0:
            raise HTTPException(404, "Registro no encontrado")
        return row_dict(db.execute(f"SELECT * FROM {table} WHERE id = ?", (item_id,)).fetchone())

    @app.delete(f"{prefix}/{{item_id}}", status_code=204)
    def delete_item(item_id: int, db: sqlite3.Connection = Depends(get_db)) -> None:
        try:
            cursor = db.execute(f"DELETE FROM {table} WHERE id = ?", (item_id,))
            db.commit()
        except sqlite3.IntegrityError as error:
            raise HTTPException(409, "Tiene registros asociados; desactívelo en vez de borrarlo") from error
        if cursor.rowcount == 0:
            raise HTTPException(404, "Registro no encontrado")

def appointment_rules(values: dict, db: sqlite3.Connection, item_id: int | None) -> None:
    if values["status"] not in STATUSES:
        raise HTTPException(422, "Estado no válido")
    if values.get("plan_id") is not None:
        plan = db.execute("SELECT patient_id, status FROM treatment_plans WHERE id = ?", (values["plan_id"],)).fetchone()
        if plan is None or plan["patient_id"] != values["patient_id"]:
            raise HTTPException(422, "El plan no existe o pertenece a otro paciente")
        if plan["status"] != "active" and values["status"] in ("scheduled", "arrived"):
            raise HTTPException(409, "El plan no está activo")
    elif item_id is not None:  # PUT sin plan_id no debe desvincular la cita de su plan
        current = db.execute("SELECT plan_id FROM appointments WHERE id = ?", (item_id,)).fetchone()
        values["plan_id"] = current["plan_id"] if current else None
    start = parse_start(values["starts_at"])
    values["starts_at"] = start.strftime("%Y-%m-%dT%H:%M")
    if values["status"] in ("cancelled", "no_show"):
        return
    end = start + timedelta(minutes=values["duration_min"])
    rows = db.execute(
        """SELECT id, starts_at, duration_min, room, professional_id, patient_id FROM appointments
           WHERE status IN ('scheduled','arrived') AND date(starts_at) = date(?) AND id IS NOT ?""",
        (values["starts_at"], item_id),
    )
    for row in rows:
        other_start = datetime.fromisoformat(row["starts_at"])
        other_end = other_start + timedelta(minutes=row["duration_min"])
        if not (start < other_end and other_start < end):
            continue
        if row["professional_id"] == values["professional_id"]:
            raise HTTPException(409, "El profesional ya tiene una cita en ese horario")
        if row["patient_id"] == values["patient_id"]:
            raise HTTPException(409, "El paciente ya tiene una cita en ese horario")
        if values["room"] and row["room"] == values["room"]:
            raise HTTPException(409, "La sala ya está ocupada en ese horario")

@app.get("/api/agenda")
def agenda(
    day: str | None = Query(default=None, description="AAAA-MM-DD; por defecto hoy"),
    professional_id: int | None = None,
    db: sqlite3.Connection = Depends(get_db),
) -> list[dict[str, Any]]:
    day = day or datetime.now().strftime("%Y-%m-%d")
    sql = """SELECT a.*, p.name AS patient_name, p.allergies, pr.name AS professional_name, pr.specialty,
                    tp.title AS plan_title, tp.total_sessions AS plan_total,
                    CASE
                      WHEN a.plan_id IS NULL THEN NULL
                      WHEN a.status IN ('scheduled','arrived') THEN
                        (SELECT COUNT(*) FROM consultations c WHERE c.plan_id = a.plan_id)
                        + (SELECT COUNT(*) FROM appointments b WHERE b.plan_id = a.plan_id AND b.status IN ('scheduled','arrived')
                             AND (b.starts_at < a.starts_at OR (b.starts_at = a.starts_at AND b.id <= a.id)))
                      WHEN a.status = 'done' THEN
                        (SELECT COUNT(*) FROM consultations c WHERE c.plan_id = a.plan_id
                           AND c.id <= (SELECT MAX(x.id) FROM consultations x WHERE x.appointment_id = a.id))
                    END AS session_no
             FROM appointments a
             JOIN patients p ON p.id = a.patient_id
             JOIN professionals pr ON pr.id = a.professional_id
             LEFT JOIN treatment_plans tp ON tp.id = a.plan_id
             WHERE date(a.starts_at) = date(?)"""
    params: list[Any] = [day]
    if professional_id is not None:
        sql += " AND a.professional_id = ?"
        params.append(professional_id)
    return [row_dict(r) for r in db.execute(sql + " ORDER BY a.starts_at", params)]

        params.append(patient_id)
    rows = [row_dict(r) for r in db.execute(sql + " ORDER BY c.occurred_at DESC, c.id DESC LIMIT ?", (*params, limit))]
    return enrich_consultations(db, rows)


@app.post("/api/consultations", status_code=201)
async def create_consultation(
    patient_id: int = Form(...),
    professional_id: int = Form(...),
    appointment_id: int | None = Form(None),
    diagnosis: str | None = Form(None),
    treatment: str | None = Form(None),
    notes: str | None = Form(None),
    plan_id: int | None = Form(None),
    eva: int | None = Form(None, ge=0, le=10),
    measurements: str | None = Form(None, description='JSON: [{"name":"Flexión rodilla","value":95,"unit":"°"}]'),
    library_ids: str | None = Form(None, description="IDs de entradas de biblioteca separados por coma"),
    attachment: UploadFile | None = File(None),
    db: sqlite3.Connection = Depends(get_db),
) -> dict[str, Any]:
    marks, links = parse_measurements(measurements), parse_ids(library_ids)
    if appointment_id is not None:
        appt = db.execute("SELECT plan_id, status FROM appointments WHERE id = ?", (appointment_id,)).fetchone()
        if appt is not None:
            if appt["status"] == "done" or db.execute("SELECT 1 FROM consultations WHERE appointment_id = ?", (appointment_id,)).fetchone():
                raise HTTPException(409, "Esa cita ya tiene su atención registrada")
            if plan_id is None:
                plan_id = appt["plan_id"]
    if plan_id is not None:
        plan = db.execute("SELECT patient_id, status FROM treatment_plans WHERE id = ?", (plan_id,)).fetchone()
        if plan is None or plan["patient_id"] != patient_id:
            raise HTTPException(422, "El plan no existe o pertenece a otro paciente")
        if plan["status"] != "active":
            raise HTTPException(409, "El plan no está activo")
    stored: str | None = None
    if attachment and attachment.filename:
        extension = Path(attachment.filename).suffix.lower()
        if extension not in {".jpg", ".jpeg", ".png", ".webp", ".pdf"}:
            raise HTTPException(415, "Solo se aceptan JPG, PNG, WEBP o PDF")
        content = await attachment.read(MAX_UPLOAD_BYTES + 1)
        if len(content) > MAX_UPLOAD_BYTES:
            raise HTTPException(413, "El archivo excede el tamaño máximo permitido")
        if not looks_like(extension, content):
            raise HTTPException(415, "El contenido del archivo no corresponde a su extensión")
        stored = f"{datetime.now(timezone.utc):%Y%m%d%H%M%S}_{secrets.token_hex(8)}{extension}"
        (UPLOAD_DIR / stored).write_bytes(content)
    try:
        cursor = db.execute(
            """INSERT INTO consultations (patient_id, professional_id, appointment_id, diagnosis, treatment, notes, attachment_path, plan_id, eva, occurred_at)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)""",
            (patient_id, professional_id, appointment_id, diagnosis, treatment, notes, stored, plan_id, eva,
             datetime.now().strftime("%Y-%m-%d %H:%M:%S")),  # hora local del servidor (fijar KINEPRO/TZ), no UTC
        )
        save_consultation_extras(db, cursor.lastrowid, marks, links)
        if appointment_id is not None:
            db.execute("UPDATE appointments SET status = 'done' WHERE id = ?", (appointment_id,))
        refresh_plan_status(db, plan_id)
        db.commit()
    except (sqlite3.IntegrityError, HTTPException) as error:
        db.rollback()
        if stored:
            (UPLOAD_DIR / stored).unlink(missing_ok=True)
        if isinstance(error, HTTPException):
            raise error
        raise HTTPException(409, f"Referencia inválida: {error}") from error
    return enrich_consultations(db, [row_dict(db.execute(CONSULTATION_SELECT + " WHERE c.id = ?", (cursor.lastrowid,)).fetchone())])[0]

def _d(row: sqlite3.Row | None) -> dict[str, Any]:

# ---------- datos de una atención (mediciones, enlaces) ----------

def parse_measurements(raw: str | None) -> list[dict[str, Any]]:
    """Convierte el JSON enviado por el formulario en filas válidas: [{name, value, unit}]."""
    if not raw or not raw.strip():
        return []
    try:
        data = json.loads(raw)
    except ValueError as error:
        raise HTTPException(422, "Mediciones con formato inválido") from error
    if not isinstance(data, list) or len(data) > 20:
        raise HTTPException(422, "Mediciones inválidas (máximo 20)")
    result = []
    for entry in data:
        try:
            name = str(entry["name"]).strip()[:60]
            value = float(entry["value"])
        except (KeyError, TypeError, ValueError) as error:
            raise HTTPException(422, "Cada medición necesita nombre y valor numérico") from error
        if not name or not -1000 <= value <= 1000:
            raise HTTPException(422, "Medición fuera de rango")
        result.append({"name": name, "value": value, "unit": str(entry.get("unit") or "°")[:8]})
    return result


def parse_ids(raw: str | None) -> list[int]:
    if not raw or not raw.strip():
        return []
    try:
        ids = [int(part) for part in raw.replace("[", "").replace("]", "").split(",") if part.strip()]
    except ValueError as error:
        raise HTTPException(422, "Lista de entradas inválida") from error
    return list(dict.fromkeys(ids))[:30]


def save_consultation_extras(db: sqlite3.Connection, consultation_id: int, measurements: list[dict], library_ids: list[int]) -> None:
    for m in measurements:
        db.execute("INSERT INTO measurements (consultation_id, name, value, unit) VALUES (?,?,?,?)",
                   (consultation_id, m["name"], m["value"], m["unit"]))
    for item_id in library_ids:
        if db.execute("SELECT 1 FROM library_items WHERE id = ?", (item_id,)).fetchone() is None:
            raise HTTPException(422, f"La entrada de biblioteca {item_id} no existe")
        db.execute("INSERT OR IGNORE INTO consultation_library (consultation_id, library_item_id) VALUES (?,?)", (consultation_id, item_id))


def enrich_consultations(db: sqlite3.Connection, rows: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Agrega `measurements` y `library` (enlaces a biblioteca) a cada atención."""
    if not rows:
        return rows
    ids = [r["id"] for r in rows]
    marks = ",".join("?" for _ in ids)
    by_c: dict[int, dict[str, list]] = {i: {"measurements": [], "library": []} for i in ids}
    for m in db.execute(f"SELECT consultation_id, name, value, unit FROM measurements WHERE consultation_id IN ({marks}) ORDER BY id", ids):
        by_c[m["consultation_id"]]["measurements"].append({"name": m["name"], "value": m["value"], "unit": m["unit"]})
    for link in db.execute(
        f"""SELECT cl.consultation_id, li.id, li.title, li.category FROM consultation_library cl
            JOIN library_items li ON li.id = cl.library_item_id WHERE cl.consultation_id IN ({marks}) ORDER BY li.title""", ids):
        by_c[link["consultation_id"]]["library"].append({"id": link["id"], "title": link["title"], "category": link["category"]})
    for r in rows:
        r.update(by_c[r["id"]])
    return rows

class PlanIn(BaseModel):
    patient_id: int
    professional_id: int | None = None
    title: str = Field(min_length=1, max_length=120)

class SeriesIn(BaseModel):

PLAN_SELECT = """SELECT tp.*, pa.name AS patient_name,
    (SELECT COUNT(*) FROM consultations c WHERE c.plan_id = tp.id) AS sessions_done,
    (SELECT COUNT(*) FROM appointments a WHERE a.plan_id = tp.id AND a.status IN ('scheduled','arrived')) AS sessions_scheduled
    FROM treatment_plans tp JOIN patients pa ON pa.id = tp.patient_id"""


def evolution(db: sqlite3.Connection, plan_id: int) -> dict[str, Any]:
    """Serie temporal de EVA y de cada medición, en orden cronológico, lista para graficar."""
    eva, measures = [], {}
    for c in db.execute("SELECT id, occurred_at, eva FROM consultations WHERE plan_id = ? ORDER BY occurred_at, id", (plan_id,)):
        date = c["occurred_at"][:10]
        if c["eva"] is not None:
            eva.append({"date": date, "value": c["eva"]})
        for m in db.execute("SELECT name, value, unit FROM measurements WHERE consultation_id = ? ORDER BY id", (c["id"],)):
            measures.setdefault(m["name"], []).append({"date": date, "value": m["value"], "unit": m["unit"]})
    return {"eva": eva, "measures": measures}


def refresh_plan_status(db: sqlite3.Connection, plan_id: int | None) -> None:
    """Un plan activo pasa a 'completed' cuando se registran todas sus sesiones."""
    if plan_id is None:
        return
    db.execute(
        """UPDATE treatment_plans SET status = 'completed' WHERE id = ? AND status = 'active'
           AND (SELECT COUNT(*) FROM consultations WHERE plan_id = ?) >= total_sessions""", (plan_id, plan_id))

    def _plan_or_404(db: sqlite3.Connection, plan_id: int) -> dict[str, Any]:

        if row is None:
            raise HTTPException(404, "Plan no encontrado")
        return dict(row)

    def _validate_plan(payload: PlanIn, db: sqlite3.Connection) -> None:
        if payload.status not in PLAN_STATUSES:
            raise HTTPException(422, "Estado de plan no válido")
        if db.execute("SELECT 1 FROM patients WHERE id = ?", (payload.patient_id,)).fetchone() is None:
            raise HTTPException(422, "Paciente no existe")
        if payload.professional_id is not None and db.execute("SELECT 1 FROM professionals WHERE id = ?", (payload.professional_id,)).fetchone() is None:
            raise HTTPException(422, "Profesional no existe")

    @router.get("/api/plans")
    def list_plans(patient_id: int | None = None, status: str | None = None, db: sqlite3.Connection = Depends(get_db)) -> list[dict[str, Any]]:
        sql, params = PLAN_SELECT + " WHERE 1=1", []
        if patient_id is not None:
            sql, params = sql + " AND tp.patient_id = ?", [*params, patient_id]
        if status:
            sql, params = sql + " AND tp.status = ?", [*params, status]
        return [dict(r) for r in db.execute(sql + " ORDER BY tp.id DESC", params)]

               VALUES (?,?,?,?,?,?,?)""",
            (payload.patient_id, payload.professional_id, payload.title, payload.reason, payload.kine_diagnosis,
             payload.total_sessions, payload.status))
        db.commit()
        return _plan_or_404(db, cursor.lastrowid)

    @router.put("/api/plans/{plan_id}")
    def update_plan(plan_id: int, payload: PlanIn, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
        _validate_plan(payload, db)
        current = _plan_or_404(db, plan_id)
        if payload.patient_id != current["patient_id"]:
            raise HTTPException(422, "No se puede cambiar el paciente de un plan")
        db.execute(
            """UPDATE treatment_plans SET professional_id=?, title=?, reason=?, kine_diagnosis=?, total_sessions=?, status=? WHERE id=?""",
            (payload.professional_id, payload.title, payload.reason, payload.kine_diagnosis, payload.total_sessions, payload.status, plan_id))
        refresh_plan_status(db, plan_id)
        db.commit()
        return _plan_or_404(db, plan_id)

    @router.post("/api/plans/{plan_id}/schedule")
    def schedule_series(plan_id: int, payload: SeriesIn, db: sqlite3.Connection = Depends(get_db)) -> dict[str, Any]:
        """Agenda varias sesiones del plan. Las que chocan se omiten y se informan; no se aborta toda la serie."""
        plan = _plan_or_404(db, plan_id)
        if plan["status"] != "active":
            raise HTTPException(409, "El plan no está activo")
        if db.execute("SELECT 1 FROM professionals WHERE id = ?", (payload.professional_id,)).fetchone() is None:
            raise HTTPException(422, "Profesional no existe")
        remaining = plan["total_sessions"] - plan["sessions_done"] - plan["sessions_scheduled"]
        if remaining <= 0:
            raise HTTPException(409, "El plan ya tiene todas sus sesiones agendadas o realizadas")
        try:
            first = datetime.fromisoformat(payload.starts_at)
        except ValueError as error:
            raise HTTPException(422, "Fecha/hora inválida (use AAAA-MM-DDTHH:MM)") from error
        created, skipped = [], []
        for n in range(min(payload.count, remaining)):
            start = (first + timedelta(days=payload.interval_days * n)).strftime("%Y-%m-%dT%H:%M")
            values = {"patient_id": plan["patient_id"], "professional_id": payload.professional_id, "starts_at": start,
                      "duration_min": payload.duration_min, "room": payload.room, "reason": plan["title"], "status": "scheduled"}
            try:
                appointment_rules(values, db, None)
            except HTTPException as error:
                skipped.append({"starts_at": start, "reason": error.detail})
                continue
            cursor = db.execute(
                """INSERT INTO appointments (patient_id, professional_id, starts_at, duration_min, room, reason, plan_id, status)
                   VALUES (?,?,?,?,?,?,?, 'scheduled')""",
                (values["patient_id"], values["professional_id"], values["starts_at"], values["duration_min"], values["room"], values["reason"], plan_id))
            created.append({"id": cursor.lastrowid, "starts_at": start})
        db.commit()
        return {"created": created, "skipped": skipped, "capped": payload.count > remaining}

    # ---------- plantillas de ejercicios para el hogar ----------

    class TemplateItemIn(BaseModel):
        library_item_id: int

    def _template(db: sqlite3.Connection, template_id: int) -> dict[str, Any]:
        row = db.execute("SELECT * FROM exercise_templates WHERE id = ?", (template_id,)).fetchone()
        if row is None:
            raise HTTPException(404, "Plantilla no encontrada")
        template = dict(row)
        template["items"] = [dict(r) for r in db.execute(
            """SELECT ti.id, ti.library_item_id, ti.dosage, ti.notes, li.title, li.region, li.summary, li.content, li.precautions
               FROM exercise_template_items ti JOIN library_items li ON li.id = ti.library_item_id
               WHERE ti.template_id = ? ORDER BY ti.position, ti.id""", (template_id,))]
        return template

    def _save_items(db: sqlite3.Connection, template_id: int, items: list[TemplateItemIn]) -> None:
        db.execute("DELETE FROM exercise_template_items WHERE template_id = ?", (template_id,))
        for position, item in enumerate(items):
            row = db.execute("SELECT category FROM library_items WHERE id = ?", (item.library_item_id,)).fetchone()
            if row is None:
                raise HTTPException(422, f"La entrada de biblioteca {item.library_item_id} no existe")
            db.execute("INSERT INTO exercise_template_items (template_id, library_item_id, dosage, notes, position) VALUES (?,?,?,?,?)",
                       (template_id, item.library_item_id, item.dosage, item.notes, position))

"""Carga la biblioteca de kinesiología desde library_data.txt (no sobrescribe ediciones)."""
import sqlite3
from pathlib import Path

DATA_FILE = Path(__file__).with_name("library_data.txt")
CATEGORIES = {
    "evaluacion": "Evaluación",
    "patologia": "Patologías",
    "ejercicio": "Ejercicios",
    "tecnica": "Técnicas y agentes",
    "anatomia": "Anatomía",
    "clinica": "Práctica clínica",
    "glosario": "Glosario",
}


def parse_library(text: str) -> list[dict]:
    items, current = [], None
    for line in text.splitlines():
        if line.startswith("## "):
            category, region, title = (part.strip() for part in line[3:].split("|", 2))
            current = {"category": category, "region": region, "title": title, "summary": "", "body": [], "precautions": [], "tags": ""}
            items.append(current)
        elif current is None or not line.strip():
            continue
        elif line.startswith("> "):
            current["summary"] = line[2:].strip()
        elif line.startswith("! "):
            current["precautions"].append(line[2:].strip())
        elif line.startswith("# "):
            current["tags"] = line[2:].strip()
        else:
            current["body"].append(line.strip())
    for item in items:
        item["content"] = "\n".join(item.pop("body"))
        item["precautions"] = "\n".join(item["precautions"])
    return items


def seed_library(db: sqlite3.Connection) -> int:
    inserted = 0
    for item in parse_library(DATA_FILE.read_text(encoding="utf-8")):
        cursor = db.execute(
            """INSERT OR IGNORE INTO library_items (category, region, title, summary, content, precautions, tags)
               VALUES (:category, :region, :title, :summary, :content, :precautions, :tags)""",
            item,
        )
        inserted += cursor.rowcount
    db.commit()
    return inserted

import csv
import io
from collections.abc import Iterable
from sqlite3 import Row


class CsvExporter:
    """Exporta filas a CSV con BOM UTF-8 para que Excel respete las tildes."""

    @staticmethod
    def _safe(value):
        """Evita inyección de fórmulas en Excel: texto que empieza con = + - @ se prefija con comilla."""
        if value is None:
            return ""
        if isinstance(value, str) and value[:1] in ("=", "+", "-", "@", "\t", "\r"):
            return "'" + value
        return value

    def export(self, rows: Iterable[Row]) -> io.StringIO:
        rows = list(rows)
        stream = io.StringIO()
        stream.write("\ufeff")
        if rows:
            writer = csv.writer(stream, delimiter=";")
            writer.writerow(rows[0].keys())
            for row in rows:
                writer.writerow([self._safe(value) for value in tuple(row)])
        return stream

let chartN = 0;
function chart(title, pts, { min, max, unit = "", judge = false } = {}) {
  if (!pts.length) return "";
  const W = 320, H = 150, L = 30, R = 14, T = 20, B = 26, id = "g" + ++chartN, vs = pts.map(p => p.value);
  let lo = min ?? Math.min(...vs), hi = max ?? Math.max(...vs); if (lo === hi) { lo -= 1; hi += 1; }
  if (min == null) { const pad = (hi - lo) * .2; lo -= pad; hi += pad; }
  const x = i => pts.length === 1 ? (L + W - R) / 2 : L + i * (W - L - R) / (pts.length - 1), y = v => T + (hi - v) * (H - T - B) / (hi - lo);
  const grid = [lo, (lo + hi) / 2, hi].map(v => `<line x1="${L}" x2="${W - R}" y1="${y(v)}" y2="${y(v)}" stroke="var(--line)"/><text x="${L - 5}" y="${y(v) + 3.5}" text-anchor="end" font-size="9" fill="var(--ink2)">${Math.round(v * 10) / 10}</text>`).join("");
  const line = pts.map((p, i) => `${i ? "L" : "M"}${x(i)},${y(p.value)}`).join(" "), area = `${line} L${x(pts.length - 1)},${H - B} L${x(0)},${H - B} Z`;
  const dots = pts.map((p, i) => `<circle cx="${x(i)}" cy="${y(p.value)}" r="4" fill="var(--surface)" stroke="var(--brand)" stroke-width="2.2"/><text x="${x(i)}" y="${y(p.value) - 9}" text-anchor="middle" font-size="10.5" font-weight="700" fill="var(--ink)">${p.value}</text><text x="${x(i)}" y="${H - 8}" text-anchor="middle" font-size="9" fill="var(--ink2)">${dm(p.date)}</text>`).join("");
  const f = pts[0].value, l = pts[pts.length - 1].value, d = Math.round((l - f) * 10) / 10;
  const delta = pts.length > 1 ? `<div class="delta"><b>${f} → ${l}${esc(unit === "0–10" ? "" : unit)}</b><span class="${judge ? (d < 0 ? "t-ok" : d > 0 ? "t-bad" : "") : ""}">${d > 0 ? "+" : ""}${d}</span></div>` : "";
  return `<div class="chartwrap"><h3 style="margin:1.2rem 0 .1rem;font-size:1rem">${esc(title)} <span class="muted" style="font-family:var(--text);font-weight:400">${esc(unit)}</span></h3>${delta}
  <svg viewBox="0 0 ${W} ${H}" role="img" aria-label="${esc(title)}: ${pts.map(p => dm(p.date) + " " + p.value).join(", ")}"><defs><linearGradient id="${id}" x1="0" y1="0" x2="0" y2="1"><stop offset="0" stop-color="var(--brand)" stop-opacity=".28"/><stop offset="1" stop-color="var(--brand)" stop-opacity="0"/></linearGradient></defs>${grid}<path d="${area}" fill="url(#${id})"/><path d="${line}" fill="none" stroke="var(--brand)" stroke-width="2.4" stroke-linejoin="round" stroke-linecap="round"/>${dots}</svg></div>`;
}
