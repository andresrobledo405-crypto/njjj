## Ejemplo 2: Análisis de Baguette + Estrategia de Growth

### Input
```
URL: https://images.unsplash.com/photo-baguette
Producto: Baguette Artesanal Tradicional
Custom Prompt: "Analiza como si fuera foto viral de TikTok/Instagram"
```

### Respuesta - Recomendaciones de Engagement

```
PREDICCIÓN DE ENGAGEMENT

TIPO DE CONTENIDO MÁS ENGAGABLE:
→ "Making Of" o "Behind the Scenes"
   Razón: El corte de baguette (sonido crujiente) = ASMR trending
   Potencial de viralizacion: 8/10

MEJOR HORA DE PUBLICACIÓN:
- Día: Lunes-Viernes
- Hora: 7:00-9:00 AM (breakfast time)
- Razón: Peak time para foodies, gente preparando desayuno
- Repost: 5:00 PM (afterwork snack time)

FORMATO RECOMENDADO:
1. Reel + Carrusel (Combina video + fotos estáticas)
2. Story con poll: "¿Cuál es tu tipo de pan favorito?"
3. Reels en bucle (20s o menos)

CTA MÁS EFECTIVO:
"¡Pide tuya hoy! Llamadas hasta las 18:00 📞 +56912345678"
Razón: Urgencia + Facilidad de compra + Horario específico

ENGAGEMENT ESTIMADO (en 7 días):
- Views: 200-500 (si no es viral)
- Likes: 30-80 (5-15% engagement rate)
- Comments: 5-15 ("¿Dónde puedo comprar?")
- Shares: 2-5 (high-intent customers)
- Saves: 10-20 (recipe/location bookmark)

TENDENCIAS A EXPLOTAR:
- #breadtok (viral en TikTok/Instagram)
- ASMR de pan (sonido de crujido)
- "Local businesses" trending
- "Artisanal/handmade" aesthetic
- #supportlocal movimiento

VERSIONES ALTERNATIVAS A PROBAR:

1. VERSIÓN A: POV "Comprar pan artesanal"
   - Persona entra a panadería
   - Elige baguette
   - Sonido de corte/crujido

2. VERSIÓN B: "Antes/Después"
   - Masa cruda → Horneado → Final
   - Time-lapse de 15s
   - Sonido de horno, ding final
   - CTA: "Así nacen nuestros panes"
```

## Cómo usar estos ejemplos

### Método 1: Copy-Paste directo
1. Copia el texto del ejemplo
2. Pega en el campo "Personalizar análisis"
3. Cambia detalles (producto, URL)
4. Click "Analizar"

### Método 2: Template
1. Guarda los ejemplos en Notion/Google Docs
2. Cada día, llena el template
3. Pasa por Gemini
4. Publica

### Método 3: Automático (Batch)
1. Prepara lista de 5-10 imágenes
2. POST /api/gemini/analyze-batch
3. Recibe análisis de todas
4. Exporta CSV
5. Programa publicaciones

## Checklist de calidad

Antes de publicar, verifica:

- [ ] SEO description tiene keywords (pan, artesanal, La Serena)
- [ ] Hashtags son trending + específicos de nicho
- [ ] CTA es claro y urgente
- [ ] Emojis son relevantes (no en exceso)
- [ ] Caption cuenta una historia
- [ ] Testimonio es específico y creíble
- [ ] Prompt Runway es detallado (150+ palabras)
- [ ] Video será 15-20 segundos máximo
- [ ] Incluye branding (@artesanospanaderials)
- [ ] Incluye CTA (WhatsApp/Link)
